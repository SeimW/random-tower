# Random Tower

This is the repository for Random Tower, a 3D open-source game made in the C++ language and with the use of the OpenGL API through the GWFL and GLAD libraries.

Random Tower is a maze game made through raycasting logic, which is seen in many older 3D games.

The goal is to grab the key and get to the goal before the ghost gets you.

Watch out, the ghost can phase through walls!

CONTROLS:

W, A, S, D -> Movement

Left and Right Arrow -> Turning

E -> Open Doors, Activate Goal (Must have key to do either!)

ENTER -> Start game

If you're having a difficult time, the console will provide a detailed map.
